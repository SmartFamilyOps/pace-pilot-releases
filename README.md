# Smart Family Ops Pace Pilot downloads

This repository distributes Pace Pilot APKs, release notes and the update manifest. Application source is maintained separately in a private repository.

Pace Pilot is an Android GPS speed display and local journey-recording prototype. The current release is a controlled in-app updater trial using the existing prototype signing identity, not a production signing-key migration.

Download only the published release artifacts. Updates must be initiated while safely parked and require Android's installation approval. Keep local journeys and settings by updating in place rather than uninstalling.

The updater reads the latest release's `roadgauge-update.json`, which identifies the version, APK URL, SHA-256 and release notes. A source commit or draft/prerelease alone does not publish an update through that URL.

Smart Family Ops: https://smartfamilyops.com/
